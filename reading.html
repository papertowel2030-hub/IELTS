Reading — Target Band 8.0

Get 36 of 40 correct in 60 minutes. GT Reading = 3 sections, easy to hard. Section 3 is hardest.

Test format (60 min, no extra transfer time)

  • Section 1 — 2–3 short texts (notices, ads) — easy
  • Section 2 — 2 work-related texts — medium
  • Section 3 — 1 long text (essay / article) — hard
  • 40 questions total. ~20 min per section. Stay STRICT on time.

How to study — daily steps

Step 1: Open British Council Reading tests. Pick ONE passage.
Step 2: Set timer to 12 minutes. Read the QUESTIONS first.
Step 3: Skim the passage for 1–2 minutes. Find the main idea per paragraph.
Step 4: Answer questions. Scan for keywords. Do not read every word.
Step 5: Check answers. Mark every wrong one. Find WHY in the text.

Top 5 rules

  • NEVER read the passage fully first. Read questions first.
  • Time per passage: ~20 min max. Skip if stuck. Come back.
  • True / False / Not Given:
    • True = passage confirms it
    • False = passage contradicts it
    • Not Given = no info either way (most common trap)
  • Don't use your own knowledge. ONLY what the text says.
  • Transfer answers as you go. No extra transfer time.

Question types — practice each one

  • True / False / Not Given — most students fail "Not Given"
  • Matching headings — read first + last sentence of each paragraph
  • Matching information — scan for specific keywords
  • Sentence completion — answer must fit grammar
  • Multiple choice — eliminate 2 wrong options first
  • Yes / No / Not Given — about author's opinion, not facts

Common mistakes that drop your band

  • Spending 30 min on Section 3 → no time for Section 2
  • Choosing "False" when answer is "Not Given"
  • Reading the whole passage before looking at questions
  • Using outside knowledge
